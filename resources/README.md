# Resources

Published parent-training files live here, one folder per collection. The folder
name must match the collection's `id` in `index.html` so links stay predictable:

```
resources/
├── digital-citizenship/
├── ai-at-home/
├── wellbeing/
├── learning-at-home/
├── school-platforms/
└── new-families/
```

**Naming:** `<topic>-<short-description>-<year>.<ext>` — lowercase, hyphenated.

**Formats:** publish the original (`.pptx`, `.docx`) so families can keep, print
or translate it. For large decks, add a `.pdf` export alongside.

See the [contributor guide](../README.md#adding-a-resource) for the full steps.
